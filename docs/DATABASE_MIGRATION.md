# Database Migration Specification (R0 / R1)

## 1. Migration Strategy
All migrations are executed programmatically in [backend/src/db/database.js](file:///c:/Project-Skill/P-S/backend/src/db/database.js) using SQLite's native `CREATE TABLE IF NOT EXISTS` and table info column inspection:
- Completely non-destructive: existing tables (`users`, `projects`, `milestones`, `tasks`, `courses`, `workspace_files`) are never truncated, dropped, or modified destructively.
- Works identically on both a fresh database and existing databases with existing projects.

---

## 2. Table Schemas

### 1. `societal_problems`
Stores the core citizen submission and lifecycle status.
```sql
CREATE TABLE IF NOT EXISTS societal_problems (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL REFERENCES users(id),
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  problem_type TEXT NOT NULL,
  category_id TEXT REFERENCES problem_categories(id),
  status TEXT DEFAULT 'SUBMITTED', -- DRAFT, SUBMITTED, AI_ANALYZING, AI_ANALYZED, REVIEW_REQUIRED, APPROVED, PUBLISHED, REJECTED, DUPLICATE, NEEDS_CLARIFICATION, ARCHIVED
  urgency TEXT DEFAULT 'medium', -- low, medium, high, critical
  severity TEXT DEFAULT 'medium', -- minor, moderate, severe, catastrophic
  people_affected TEXT, -- e.g. "500+", "10,000"
  geographic_scope TEXT DEFAULT 'local', -- local, district, regional, national
  privacy_level TEXT DEFAULT 'locality', -- exact, locality, district, approximate
  expected_impact TEXT,
  structured_impact TEXT DEFAULT '{}', -- JSON with social, economic, environmental notes
  adopted_by TEXT REFERENCES users(id), -- Mentor/university who adopted
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2. `problem_media`
Stores uploaded media metadata safely decoupled from file content.
```sql
CREATE TABLE IF NOT EXISTS problem_media (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  media_type TEXT NOT NULL, -- 'image' or 'video'
  file_name TEXT NOT NULL,
  original_name TEXT NOT NULL,
  mime_type TEXT NOT NULL,
  size_bytes INTEGER NOT NULL,
  storage_path TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 3. `problem_locations`
Stores geographic coordinates with privacy masking metadata.
```sql
CREATE TABLE IF NOT EXISTS problem_locations (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  latitude REAL,
  longitude REAL,
  formatted_address TEXT,
  district TEXT,
  state TEXT,
  country TEXT DEFAULT 'India',
  privacy_level TEXT DEFAULT 'locality',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4. `problem_ai_analysis`
Stores structured technical analysis generated by `problemIntelligence.js`.
```sql
CREATE TABLE IF NOT EXISTS problem_ai_analysis (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  summary TEXT,
  problem_statement TEXT NOT NULL,
  primary_category TEXT,
  secondary_categories TEXT DEFAULT '[]', -- JSON
  affected_stakeholders TEXT DEFAULT '[]', -- JSON
  root_causes TEXT DEFAULT '[]', -- JSON
  key_requirements TEXT DEFAULT '[]', -- JSON
  constraints TEXT DEFAULT '[]', -- JSON
  urgency TEXT,
  severity TEXT,
  estimated_scope TEXT,
  expected_impact TEXT,
  potential_solution_domains TEXT DEFAULT '[]', -- JSON
  required_skills TEXT DEFAULT '[]', -- JSON
  recommended_project_type TEXT,
  recommended_team_roles TEXT DEFAULT '[]', -- JSON
  technology_domains TEXT DEFAULT '[]', -- JSON
  confidence REAL DEFAULT 0.0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5. `problem_categories`
Pre-seeded and configurable categories.
```sql
CREATE TABLE IF NOT EXISTS problem_categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  slug TEXT NOT NULL UNIQUE,
  icon TEXT,
  description TEXT,
  is_active INTEGER DEFAULT 1
);
```

### 6. `problem_reviews`
Audit log of admin / university reviews.
```sql
CREATE TABLE IF NOT EXISTS problem_reviews (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  reviewer_id TEXT NOT NULL REFERENCES users(id),
  verdict TEXT NOT NULL, -- approved, rejected, needs_clarification
  review_notes TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 7. `problem_duplicates`
Candidate duplicate tracking with similarity percentages.
```sql
CREATE TABLE IF NOT EXISTS problem_duplicates (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  matched_problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  similarity_score REAL NOT NULL, -- e.g. 0.91 (91%)
  reasoning TEXT,
  status TEXT DEFAULT 'pending', -- pending, confirmed, dismissed
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 8. `problem_interests`
Student expressions of interest.
```sql
CREATE TABLE IF NOT EXISTS problem_interests (
  id TEXT PRIMARY KEY,
  problem_id TEXT NOT NULL REFERENCES societal_problems(id) ON DELETE CASCADE,
  user_id TEXT NOT NULL REFERENCES users(id),
  role_preference TEXT,
  note TEXT,
  status TEXT DEFAULT 'pending', -- pending, accepted, rejected
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
